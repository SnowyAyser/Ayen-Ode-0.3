# Objects

One file per significant object. Name files as `<world-slug>-<object-slug>.md`.

---

## Record Fields

| Field | Description |
|-------|-------------|
| `name` | Object name |
| `world` | World slug |
| `type` | weapon / artifact / document / relic / tool / other |
| `status` | intact / damaged / lost / destroyed / contested / unknown |
| `summary` | 2–4 sentences on what it is, what it does, and why it matters |
| `current_holder` | Who possesses it right now, if known |
| `origin` | Where it came from or who made it |
| `linked_entities` | Characters, factions, or locations tied to this object |
| `stat_profile` | Key stats snapshot — potency, rarity, durability, etc. |
| `continuity_notes` | How ownership, condition, or knowledge of it has changed |
| `open_pressures` | Who wants it, fears it, or is hunting it |
