# Characters

One file per character. Name files as `<world-slug>-<character-slug>.md`.

---

## Record Fields

| Field | Description |
|-------|-------------|
| `name` | Character's name |
| `world` | World slug this character belongs to |
| `role` | Narrative role — protagonist, antagonist, ally, neutral, etc. |
| `status` | active / injured / captured / dead / missing / unknown |
| `summary` | 2–4 sentences on who they are and what they want |
| `private_truth` | What is true about them that the player does not yet know |
| `motive` | What they are fundamentally after |
| `fear` | What they avoid or cannot face |
| `limit` | What they will not do, no matter the pressure |
| `linked_entities` | Other entities they are meaningfully connected to |
| `stat_profile` | Key stats snapshot (full sheet in server) |
| `continuity_notes` | Important changes, injuries, revelations, or turning points |
| `open_pressures` | Unresolved tensions currently shaping their behavior |
