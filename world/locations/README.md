# Locations

One file per location. Name files as `<world-slug>-<location-slug>.md`.

---

## Record Fields

| Field | Description |
|-------|-------------|
| `name` | Location name |
| `world` | World slug |
| `type` | city / region / building / ruin / wilderness / other |
| `status` | active / contested / destroyed / abandoned / unknown |
| `summary` | 2–4 sentences on what this place is and feels like |
| `controlling_faction` | Who holds authority here, if anyone |
| `linked_entities` | Characters, factions, or objects meaningfully tied to this place |
| `stat_profile` | Key stats snapshot — security, danger, stability, etc. |
| `continuity_notes` | Events that changed this place, who has passed through, battles, etc. |
| `open_pressures` | Active threats or changes shaping this location right now |
