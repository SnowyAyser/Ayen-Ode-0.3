# Events

One file per significant event. Name files as `<world-slug>-<event-slug>.md`.

---

## Record Fields

| Field | Description |
|-------|-------------|
| `name` | Event name or short description |
| `world` | World slug |
| `type` | battle / revelation / betrayal / death / discovery / political / natural / other |
| `status` | unfolding / resolved / aftermath / unknown |
| `summary` | 2–4 sentences on what happened and why it matters |
| `key_participants` | Entities directly involved |
| `outcome` | What the event resulted in, if resolved |
| `linked_entities` | Entities affected or changed by this event |
| `stat_profile` | Key stats snapshot — scale, fallout, momentum, etc. |
| `continuity_notes` | How canon was changed by this event |
| `open_pressures` | Unresolved consequences still shaping the story |
