# Factions

One file per faction. Name files as `<world-slug>-<faction-slug>.md`.

---

## Record Fields

| Field | Description |
|-------|-------------|
| `name` | Faction name |
| `world` | World slug |
| `type` | political / criminal / religious / military / mercantile / secret / other |
| `status` | active / weakened / fractured / collapsed / emerging |
| `summary` | 2–4 sentences on who they are, what they want, and how they operate |
| `leadership` | Who is currently in control and how stable that is |
| `motive` | The faction's core goal or driving pressure |
| `methods` | How they typically pursue their goals |
| `linked_entities` | Key characters, locations, or objects tied to this faction |
| `stat_profile` | Key stats snapshot — power, cohesion, reach, etc. |
| `continuity_notes` | Major events, betrayals, victories, or losses |
| `open_pressures` | Internal or external threats currently shaping the faction |
