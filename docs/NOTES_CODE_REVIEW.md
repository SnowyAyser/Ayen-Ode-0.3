### File-truncation note (discovered this pass)

The `Edit` tool truncates files to their original byte size when net bytes are added. Specifically,
content inserted near the top of a file causes an equal number of bytes to be silently dropped from
the end. The bash `cat >>` and `cat > HEREDOC` patterns are **reliable workarounds** and should be
used for any edit that increases a file's byte count.
